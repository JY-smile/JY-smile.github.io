# 专升本快速查

安徽省专升本专科专业查询工具，输入专科专业名称，快速查询可报考的本科院校及招生专业信息。

## 在线使用

👉 **[点击这里立即使用](https://codedocky.github.io/)**

> GitHub Pages 地址：https://codedocky.github.io/

## 功能介绍

- 🔍 **智能搜索** — 输入专科专业名称，自动提示匹配结果
- 🏫 **公办/民办分类** — 按院校性质分类展示，一目了然
- 📊 **数据统计** — 显示院校总数、公办/民办数量、招生专业数
- 📋 **详细信息** — 展示招生专业、科类、招生人数、学费、考试科目
- 📱 **响应式设计** — 支持手机、平板、电脑访问

## 数据说明

- 数据来源：安徽省普通高校专升本招生专业范围
- 数据内嵌于 `index.html` 中，无需服务器，直接打开即可使用
- 本工具仅供查询参考，正式报考请以官方发布信息为准

## 本地使用

直接双击 `index.html` 用浏览器打开即可，无需安装任何依赖。

## 技术说明

- 纯前端实现（HTML + CSS + JavaScript）
- 数据已内嵌到 HTML 文件中
- 可部署到任何静态网站托管服务（GitHub Pages、Netlify、Vercel 等）
