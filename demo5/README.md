# 📊 2026年专升本报考录取预测系统

基于历年招生计划、报录比、录取分数及2026真题难度的多因子数理预测模型。

## 功能特性

- **模糊搜索专业**：输入专业名称即可模糊匹配，支持132个专业
- **专业科类智能识别**：自动判断专业属于文科/理科/文理兼收，锁定或开放科类选择
- **公共课+专业课分离输入**：分别输入公共课预估总分（满分300）和专业课预估总分（满分300）
- **多因子预测模型**：综合报录比变化、趋势修正、招生计划调整、极端值修正、真题难度修正五大因子
- **2026真题难度修正**：基于公共课真题难度评估，对预测线进行方向性修正
- **录取等级判定**：危险🔴 / 接近🟡 / 达标🟢 / 超稳定🔵 四级评估
- **多维度排序筛选**：按等级、预测线、院校、报录比排序，按等级筛选
- **详细逻辑分析报告**：包含真题难度影响、分科表现、报考策略建议等

## 考试结构

```
总分600分 = 公共课300分 + 专业课300分

文科公共课：大学语文150分 + 英语150分
理科公共课：高等数学150分 + 英语150分
专业课：两门专业课各150分，合计300分
```

## 2026真题难度评估

| 科目 | 难度 | 预测线影响 |
|------|------|-----------|
| 大学语文 | 中等偏易 | 文科预测线 +5分 |
| 英语 | 中等 | 持平微升 |
| 高等数学 | 中等偏难 | 理科预测线 -4分 |

## 预测模型

```
2026预测分数线 = 2025录取分
  + 报录比变化调整（弹性系数2.5 × 相关性0.575）
  + 趋势修正（近两年趋势加权）
  + 招生计划变化调整
  + 极端报录比修正
  + 真题难度修正（文科+5 / 理科-4）
```

### 等级判定标准

| 等级 | 条件 | 含义 |
|------|------|------|
| 🔴 危险 | 用户分数 < 预测线×95% | 录取可能性较低 |
| 🟡 接近 | 预测线×95% ≤ 用户分数 < 预测线 | 擦线区间，存在风险 |
| 🟢 达标 | 预测线 ≤ 用户分数 < 预测线×105% | 录取概率较大 |
| 🔵 超稳定 | 用户分数 ≥ 预测线×105% | 录取概率极高 |

## 数据说明

`data.json` 包含2023-2026年各院校各专业的招生计划、报录比、录取分数等数据，其中2026年录取分数为预测值。

## ⚠️ 免责声明

- 本系统基于历史数据的统计规律，实际录取分数受多种因素影响
- 真题难度修正基于回忆版试卷的定性评估，实际感受因人而异
- 部分专业历史数据缺失，预测置信度较低
- 结果仅供参考，请结合官方发布的招生政策综合判断
